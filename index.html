Metro's Zoning Generalized Classifications

Metro created these 48 generalized zoning classifications to standardize zoning codes across the metro area, which vary by city. The tool falls back to these classifications when a taxlot either a) does not have data for a Portland zone code or b) has a Portland zone code whose density is capped by FAR, not units/acre (that is, RM1, RM2, RM3, RM4, and RX).
